# 100 Days of Machine Learning — CampusX

A concise, student-friendly companion repository for the CampusX **100 Days of Machine Learning** course. This repo contains notes, example code, and small experiments created while following the course.

## About

I am actively following the CampusX course and continuously adding content for each class. Materials are written from a student's perspective with clarity and practical examples.

## What's Included

- Well-structured Python code for each day's topics and assignments
- Detailed lecture notes written from a student's perspective
- Key points, formulas, and intuition for quick revision
- Small experiments, practice notebooks, and mini-projects to reinforce concepts

## Repository Structure

- `day 1.txt`, `day 2.txt`, ... — Daily notes and short explanations
- Notebooks/ — (optional) Jupyter notebooks for hands-on experiments
- code/ — (optional) Example implementations and scripts

> Note: File and folder names may evolve as content is added.

## How to Use

1. Browse the day folders or daily files to review notes and code.
2. Open notebooks in VS Code or Jupyter to run examples interactively.
3. Use the repo as a revision aid or to re-implement examples for practice.
